# 3. Design Direction

## Main Theme

**Cyberpunk**

The design should be futuristic, energetic, experimental, and premium while remaining clean and usable.

Avoid making the website look like a noisy gaming website.

The cyberpunk aesthetic should come mainly from:

- Typography
- Neon accents
- Dark surfaces
- Subtle glow
- Grid patterns
- Technical details
- Motion
- HUD-inspired elements
- Digital/terminal-inspired micro-details
- Strong contrast
- Carefully controlled gradients

The design must remain professional enough for clients, recruiters, and companies.

## Recommended Visual Direction

Base:

- Very dark background
- Near-black surfaces
- High-contrast typography
- Neon blue as the primary accent
- Neon green/cyan as secondary accents
- Occasional purple/magenta glow only when useful
- Thin borders
- Glass-like surfaces used sparingly
- Soft neon shadows
- Subtle background grid/noise

Do not overuse glow effects.

## Typography

Use a modern futuristic/technical font pairing.

Preferred:

- Space Grotesk for major UI/heading typography
- A compatible monospace font for small technical labels

If the existing project already uses Kanit successfully, evaluate the existing design before replacing it. Do not change typography unnecessarily if doing so would break the established visual system.

# 17. Animation Rules

Use Framer Motion for React animations.

Animation style:

- Smooth
- Premium
- Controlled
- Fast enough to feel responsive
- Never distracting

Use:

- Fade
- Slide
- Scale
- Blur-to-sharp
- Stagger
- Scroll reveal
- Magnetic movement
- Subtle parallax

Avoid:

- Excessive bouncing
- Constant movement
- Long loading animations
- Huge unexpected transforms
- Animations that make text difficult to read

Respect `prefers-reduced-motion`.

# 19. Responsive Design

The website must work well on:

- Mobile
- Tablet
- Laptop
- Desktop
- Large/ultra-wide displays

Mobile is not an afterthought.

On mobile:

- Simplify decorative effects.
- Reduce large typography when necessary.
- Keep navigation usable.
- Prevent horizontal overflow.
- Make project cards easy to browse.
- Ensure buttons have comfortable touch targets.
- Disable or simplify expensive cursor effects.

---

# 20. Accessibility

Follow good accessibility practices:

- Semantic HTML
- Keyboard navigation
- Visible focus states
- Proper button elements
- Meaningful alt text
- Sufficient text contrast
- Accessible form labels
- Reduced-motion support

Do not sacrifice usability for the cyberpunk aesthetic.

---

# 21. Performance

Keep the website fast.

Rules:

- Lazy-load project images when appropriate.
- Optimize large images.
- Avoid unnecessary dependencies.
- Avoid excessive DOM animation.
- Use transforms for animation where possible.
- Avoid heavy continuous effects.
- Do not load multiple large assets unnecessarily.
- Keep the first viewport fast.
